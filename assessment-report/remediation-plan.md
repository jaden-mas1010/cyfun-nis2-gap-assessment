# Remediation Plan

This remediation plan prioritises actions required to achieve NIS2 readiness. Items are grouped into immediate, short‑term, and long‑term phases based on urgency, regulatory impact, and organisational risk.

---

## 🚨 Immediate Actions (0–14 days)

### 1. Establish Cybersecurity Roles & Responsibilities  
- Assign a security lead or CISO-equivalent role  
- Define accountability for governance, risk, and incident response  
- Document responsibilities in an organisational security policy  

### 2. Implement Basic Logging & Monitoring  
- Enable system and application logs  
- Centralise logs where possible  
- Begin monitoring critical events (authentication, access, configuration changes)  

### 3. Create an Incident Reporting Workflow  
- Define incident severity levels  
- Establish escalation paths  
- Document reporting timelines aligned with NIS2 Article 23  
- Train staff on how to report incidents internally  

---

## 🧩 Short-Term Actions (1–3 months)

### 4. Deploy Vulnerability Management  
- Implement regular vulnerability scanning  
- Prioritise remediation based on CVSS scores  
- Track vulnerabilities in a central register  

### 5. Implement Access Control Policies  
- Enforce least privilege  
- Introduce role-based access control (RBAC)  
- Review and remove unused accounts  
- Enable MFA for critical systems  

### 6. Conduct Supplier Risk Assessments  
- Evaluate security posture of critical vendors  
- Introduce contractual security requirements  
- Begin monitoring third-party risks  

### 7. Develop Business Continuity Plans  
- Create BCP and DRP documentation  
- Define recovery time objectives (RTO) and recovery point objectives (RPO)  
- Conduct tabletop exercises  

---

## 🏗️ Long-Term Actions (3–12 months)

### 8. Align with ISO 27001  
- Implement Annex A controls  
- Formalise risk management methodology  
- Build an internal audit cycle  

### 9. Implement Full NIS2 Governance Framework  
- Establish cybersecurity governance board  
- Integrate risk management into organisational strategy  
- Conduct annual NIS2 compliance reviews  

### 10. Conduct Regular Audits & Exercises  
- Perform quarterly security audits  
- Run incident response simulations  
- Test business continuity and crisis communication plans  

---

## ✔ Summary

This remediation plan provides a structured path toward NIS2 compliance.  
Immediate actions reduce critical exposure, short‑term actions build operational capability, and long‑term actions establish sustainable governance and regulatory alignment.
