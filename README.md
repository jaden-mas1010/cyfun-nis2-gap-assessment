# # CyFun & NIS2 Readiness Assessment

## Overview
Independent cybersecurity governance project assessing a simulated financial services organisation against the Cyber Fundamentals (CyFun) framework and NIS2 Directive requirements.

## Objectives
- Assess organisational cybersecurity maturity
- Identify compliance gaps
- Prioritise risks
- Develop a remediation roadmap

## Frameworks
- CyFun
- NIS2 Directive
- NIST CSF
- ISO 27001:2022

## Deliverables
- Gap Assessment Report
- Risk Register
- Executive Summary
- Remediation Roadmap

## Key Findings
- 3 High Risks
- 4 Medium Risks
- 2 Low Risks

## Skills Demonstrated
- Cyber Risk Assessment
- GRC
- NIS2 Compliance
- ISO 27001
- Risk Register Development
- Executive Reporting
